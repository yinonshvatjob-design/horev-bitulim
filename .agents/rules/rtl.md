# Right-To-Left Text Alignment

The user STRONGLY PREFERS that all Hebrew text be aligned to the right. Whenever responding in Hebrew to the user, you MUST wrap your entire response inside an HTML div like this:

<div dir="rtl">
(Your response here)
</div>

This ensures that the web UI properly aligns the text from right to left.
